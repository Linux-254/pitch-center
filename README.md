# CyTech Studios Pitch Center

High-converting business growth engine, digital menus, 24/7 AI chatbot concierge, and direct outreach command center engineered for Kenyan businesses and international clients.

---

## Features

- **Direct Pitch Dispatcher**: Send personalized outreach scripts directly via WhatsApp (`wa.me`) or Email (`mailto:`) in under 10 seconds.
- **Dual-Device 45-Second Showcase**: Simultaneous Desktop and Mobile views with a 45-second interactive walkthrough demonstrating QR scanning, visual photo ordering, 2s AI reply, and live POS sync.
- **Live Admin & POS Operations Dashboard**: Real-time kitchen display tickets, verified M-Pesa revenue tracking, and conversational AI lead capture CRM.
- **7 High-Conversion Business Verticals**:
  - Restaurants, Bars & Lounges (QR Table Ordering & Digital Menu)
  - Salons, Barbers & Spas (Editorial Luxury Theme)
  - Clinics & Dentists (Clean Clinical Sans-Serif)
  - Real Estate (Architectural Splitscreen)
  - Gyms & Fitness (High-Energy Contrast Dark Mode)
  - Schools & Driving Academies (Friendly Approachable Cards)
  - Car Dealerships & Boutiques (Dark Chrome Metallic Layout)
- **Zero Emojis**: 100% crisp inline SVG icons, clean typography, and modern micro-animations.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Linux-254/pitch-center.git
cd pitch-center

# Install dependencies
npm install

# Start local server
node server.js
```

Open `http://localhost:3005` in your browser.
